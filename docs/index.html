Easy Theme

Easy Theme for Unreal Engine 5

Clean. Compact. Readable. Dark by default, Light included. Free and open source.

Download Source on GitHub Support

Dark, the default. Square controls, crisp 1-pixel frames, compact toolbars.

Light, switched live from Window > Easy Theme.

Graphs follow the mode. Your grid colours are always restored.

Pixel-exact bevels, no blur.

Every editor, every panel.

Install: unzip the download into YourProject/Plugins/ and start the editor. Options: Window > Easy Theme. Editor-only, no telemetry.
