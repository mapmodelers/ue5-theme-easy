Easy Theme

Easy Theme for Unreal Engine 5

Clean. Compact. Readable. Dark by default, Light included.

GitHub Support
  • Dark and Light, switched live from Window > Easy Theme.
  • Compact: thinner tabs and toolbars, more room for work.
  • Pixel-exact: square, bevelled controls with no blur.
  • Readable everywhere: no stray dark panels or invisible text.
  • Graphs follow the mode: Blueprint and Material.
  • Slim title bar: no oversized logo.
  • Optional 3-pane layout in Window > Load Layout.
  • Editor-only: no engine changes; disable to remove.
