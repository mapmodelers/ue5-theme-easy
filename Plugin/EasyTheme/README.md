# Easy Theme

Clean, compact, high-clarity editor theme for Unreal Engine 5. Dark by default, Light included.

- Switch: Window > Easy Theme > Dark / Light (live). Console: `EasyTheme.Dark 1` / `0`.
- Light graphs (Light mode): Window > Easy Theme > Light Graphs. Your grid colours are restored when off.
- Rebuild every panel: Window > Easy Theme > Refresh UI.
- Optional layout: Window > Easy Theme > Use 3-Pane Layout.
- Uninstall: Window > Easy Theme > Remove Saved Settings, then disable the plugin (Edit > Plugins) or remove it in the Epic Games Launcher. Editor-only, no engine files changed.

Docs and support: https://github.com/mapmodelers/ue5-theme-easy
